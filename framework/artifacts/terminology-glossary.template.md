## 3. Domain Cluster Map

|---------|-------|----------------|-------------|
| {Cluster Label} | `{term1}`, `{term2}`, `{term3}`, ... | MOD-XXX ({Name}) | {one-line domain description} |

**Cluster formation:**
1. Two terms co-occur if they appear in the same module's keyword list OR in the same compound symbol name (e.g., `UserProfile` co-occurs `User` with `Profile`)
2. Terms are grouped into a cluster if they co-occur in >=2 modules, or appear together in >=3 compound symbol names
3. Cluster label = the most frequent functional capability label from the primary module
