## 1. Constant-to-Module Index

*All constants across the project. Use this index to find whether an equivalent constant already exists before defining a new one.*

| Constant | Kind | Value / Type | Location | Category | Defining Module |
|----------|------|-------------|----------|----------|-----------------|
| `{name}` | {const \| enum \| enum-member \| as-const} | `{value or type summary}` | `src/path/file.ts:{line}` | {category} | MOD-XXX ({Name}) |

**Category codes:**
| Code | Description | Detection Rule |
|------|-------------|---------------|
| `API` | API path / endpoint URL | Name starts with `API_`, `ENDPOINT_`, `ROUTE_`, `URL_`, `PATH_` |
| `ERR` | Error code | Name starts with `ERR_`, `ERROR_`, `ERRCODE_` |
| `CFG` | Configuration key | Name starts with `CFG_`, `CONFIG_`, `SETTING_`, `OPTION_` |
| `ENUM` | Enumeration | `enum` keyword or `as const` with string/number members |
| `MSG` | Message template | Name starts with `MSG_`, `MESSAGE_` |
| `FLAG` | Feature flag / toggle | Name starts with `FEATURE_`, `FLAG_`, `TOGGLE_` or boolean const |
| `REGEX` | Regex pattern | Name starts with `REGEX_`, `PATTERN_`, `RE_` |
| `DEFAULT` | Default / fallback value | Name starts with `DEFAULT_`, `FALLBACK_` |
| `MAGIC` | Magic number / inline literal | Numeric literal without descriptive name or unit context |
| `OTHER` | Other | Fallback for constants that don't match any category |
